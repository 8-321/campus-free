# 白拿 · 校园免费捡漏

把校园里正在被免费送掉的东西（剩菜、教材、名额、闲置）收拢到一个页面，按距离由近到远排列。学生打开第一眼就知道「我 500 米内现在有什么可以白拿」。

纯 HTML / CSS / JS，四个文件，零依赖、零构建、零 npm。

```
index.html   styles.css   app.js   data.js
assets/photos/   28 张图（14 条 × 4:3 卡片 + 16:9 详情）
assets/qr.png    课堂扫码用
```

本地跑：`python -m http.server 8123` → http://127.0.0.1:8123/
（不要双击 index.html：`file://` 下图片和脚本行为不一致，静态服务最稳。）

## 1 PRD（≤600 字）

**对标**：Olio（邻里免费赠送社区 + Olio Plus 订阅，公开口径约 $30k/月量级）。结构拆成四层：

1. **半径即 feed**：唯一排序轴是距离，没有"推荐"；
2. **单物品单帖**：供给成本≈拍照+一句话，所以供给能自己长出来；
3. **双向确认**：领取要凭证（Olio 用私信，校园版用 4 位码），不交换身份；
4. **订阅层**：付费买"更早知道"（优先看新货、提醒、无广告），而不是买内容。

**校园版成立的三条件**

- **供给密度**：宿舍/食堂/教室每天产出可送物，500 米内一天几十件才撑得起"每次打开都有货"；
- **距离足够短**：步行 ≤5 分钟，"顺路拿"的决策成本低于"扔掉"的愧疚成本；
- **双方都不愿露身份**：不愿加微信、不愿给学号，所以凭证必须是无身份的（4 位数字，当面口头核验）。

**5 条核心机制**

1. **距离即排序**：默认米数升序，首屏标题直接说"9 样东西，在你 500 米内"；
2. **时效压力**：<30 分钟才变砖红，制造"现在就走"；
3. **四位数凭证**：领取码在领取方本地生成，当面报数，零身份交换；
4. **一条一路径**：发布必须填地点 + 剩余时间，禁止模糊帖；
5. **省钱账单**：把白拿折算成金额（¥18、¥45），给回访一个理由。

**商业化一句话**：Pro ¥6/月，卖「30 分钟内新货优先看 + 到货提醒」，免费流量不做推荐位。
**冷启动一句话**：先在 2 栋宿舍 + 1 个食堂做「每晚 21:30 统一清仓」的定点供给，两周把 500 米内日均做到 20 件，再扩校区。

## 2 UI / 交互

- **首页**：hero（用距离说话）→ 6 分类 chips（带条数）→「手慢无」横滑 → 按距离分档列表（100 / 300 / 500 / 1.2km）
- **详情面板**：16:9 实拍图 + 距离 30px 主视觉 + 地点/估值/发布者 + 三步「怎么拿」+ 底部领取
- **领取**：点击生成 4 位码，码存入「我的」；卡片时间位显示"已领取 8019"
- **发布**：标题 / 分类 / 距离 / 有效期 / 地点 / 说明 / 配图 → 提交后进「刚刚发布」档，排第一
- **我的**：省钱账单（数字滚动，`Date.now()` 驱动、结束写终值）+ 领取记录 + Pro 卡

## 5 隐私

- 无真实姓名、学号、手机号、宿舍号、微信、邮箱、学校全称；地点全部为虚构，集中在 `data.js` 的 `CAMPUSES` 常量，改一处即可换成真实校区。
- 无任何 key / token / 密码；不发需要登录态的请求；状态只写本机 `localStorage`。
- 图片为公开演示素材，**上线前请替换为自有版权照片**（页脚已标注「演示图」）。
- 仓库为 public：源码全网可见，替换数据时先脱敏。
